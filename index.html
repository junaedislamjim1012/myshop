How to Run the Full App with Database

GitHub Pages provides this static frontend view. To run the full dynamic PHP backend, follow these easy steps:

Deploy on cPanel (Recommended)

Live production hosting in 5 minutes

  1. Download or clone this repository as a ZIP archive.
  2. In cPanel File Manager, extract the files to your domain directory.
  3. Create a MySQL database in cPanel MySQL Databases.
  4. In phpMyAdmin, select your database and import:
    creativedesignbd_myshop3.sql
  5. Rename .env.example to .env and set your DB name, user, password, and APP_URL.
  6. Point your domain Document Root to the public folder.

Run on Localhost (Windows / Mac / Linux)

Using XAMPP, Laragon, or Docker

# 1. Clone repository

git clone https://github.com/junaedislamjim1012/myshop.git

cd myshop

# 2. Install dependencies

composer install

npm install && npm run build

# 3. Configure .env & Database

cp .env.example .env

php artisan key:generate

# 4. Import SQL and Start

php artisan storage:link

php artisan serve
